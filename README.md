## ⭐ Featured — [Aktar](https://github.com/ardazeybek-dev/aktar)

> **Reads a bank statement, works out who paid what, and enters the records into a web panel for you.**

<p align="center">
  <a href="https://github.com/ardazeybek-dev/aktar">

  </a>
</p>

<p align="center">
  <img src="https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white" alt="python" />

  <img src="https://img.shields.io/badge/tests-200%20passing-brightgreen?style=flat-square" alt="tests" />
  <a href="https://github.com/ardazeybek-dev/aktar/releases"><img src="https://img.shields.io/badge/Windows-download-0078D6?style=flat-square&logo=windows&logoColor=white" alt="download" /></a>

A preschool types 80–130 parent payments into a government panel every month —
nine or ten clicks each, about two full working days. The clicking was never the
hard part. **Understanding the statement was.**

Parents write whatever they like in the transfer description: the child's name
first, last, or missing entirely; a surname short its first letter
(`beren artal` → **Beren KARTAL**); the word for "club" spelled four different
ways; four families sharing one surname; and donations, canteen income and rent
mixed in that must *never* be entered.

**What makes it hold up in production:**

- 🔎 **Selectors that survive a redeploy** — the target panels are legacy ASP.NET WebForms, where ids like `ctl00$ContentPlaceHolder1$txtEvrakNo` shift between releases and break automation silently. Aktar locates each field by the **label text on screen** instead, restricted to leaf nodes so a `<div>` wrapping the whole page cannot match
- 🇹🇷 **Turkish fuzzy name matching** — a normalisation layer over `rapidfuzz`: folding `ğ/ü/ş/ı/ö/ç`, stripping month names and banking noise (`gönd`, `fast işlemi`, `havale`, `aidat`), then token-based scoring
- ⚖️ **It refuses to guess** — even at a score of 91, if the runner-up sits at 88 the row is marked *uncertain* and handed back to the user. When two families share a surname, a high score does not mean *correct*, and a misattributed payment costs far more than one confirmation click
- 🧩 **Panel-agnostic** — everything site-specific lives in a recipe file, so supporting a new panel is a config change, not a rewrite

## 📦 Published Packages

Software other people install and depend on. Every one of them exists because
the problem is specific to Türkiye and nobody had packaged the answer.

| Package | What it solves | Install |
| --- | --- | --- |
| **[kvkk](https://github.com/ardazeybek-dev/kvkk)** | Finds and masks Turkish personal data — TCKN, IBAN, VKN, payment cards, phones — in files, logs and database dumps. Checksum-verified, so an order number never becomes an incident. The report itself is masked, so it never becomes the second leak. Four masking strategies, including one that emits *valid* fake values for staging databases | `pip install kvkk` · [PyPI](https://pypi.org/project/kvkk/) |
| **[trkit](https://github.com/ardazeybek-dev/trkit)** | Python's `"istanbul".upper()` returns `ISTANBUL` and quietly corrupts every Turkish name and city it touches. trkit gets the dotted/dotless `i` right, and validates TCKN, IBAN and licence plates. 107 tests, CI on Linux + Windows across Python 3.10–3.13 | `pip install trkit` · [Demo](https://trkit-arda.shipstatic.com) |
| **[bordro](https://github.com/ardazeybek-dev/bordro)** | Turkish payroll in TypeScript — gross↔net, employer cost, and the twelve-month cumulative income tax that almost every online calculator gets wrong. Zero dependencies, 40 tests | [Demo](https://ardazeybek-dev.github.io/bordro/) |
